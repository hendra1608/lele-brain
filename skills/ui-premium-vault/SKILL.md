# UI Premium Vault
## Trigger
The primary deliverable is a user-facing interface or UX decision.
## Scope
Visual quality is conditional on product context; operational usability and accessibility take precedence for enterprise workflows.
## Required Context
Read applicable AGENTS.md, project wiki, repository conventions, and only the source files needed to establish current behavior.
## Inputs
The user goal, affected repositories/modules, constraints, and available validation commands.
## Workflow
1. Discover design system, target users, task frequency, density, and accessibility requirements.
2. Design loading, error, empty, permission, keyboard, and responsive states before decoration.
3. Add visual differentiation or motion only when it improves comprehension and fits the existing stack.
## Outputs
State the decision, evidence, changes, validation results, and unresolved risks. Do not claim completion without evidence.
## Validation
Review keyboard flow, contrast, responsive layout, semantic labels, and realistic data states.
## Stop Conditions
Stop and ask for clarification when a required contract, security decision, production-data policy, or destructive action is ambiguous. Do not expand scope merely because a related pattern exists.
## Safety Boundaries
Do not mandate Framer Motion, glassmorphism, custom scrollbars, or visual effects for ordinary operational screens.
