# Wiki Compiler Workflow
1. Prefer the active repository's `wiki/` when it exists or the user requests repository onboarding/docs.
2. Use Lele Brain project memory only for cross-session project facts that are safe to retain outside the repository.
3. Link decisions and patterns to authoritative source paths; avoid copying large code blocks or generated artifacts.
4. Validate links, freshness, scope, and sensitive-data exclusions before publishing.
